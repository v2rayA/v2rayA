# گزینه‌ها و متغیرهای محیطی

هر گزینه یک متغیر محیطی هم‌نام دارد: متغیر محیطی متناظر با گزینهٔ `--log-level`، `V2RAYA_LOG_LEVEL` است. واحد سرویس Linux، متغیر `V2RAYA_LOG_FILE` را تنظیم می‌کند و `/etc/default/v2raya` را می‌خواند؛ بقیهٔ گزینه‌ها مقدار پیش‌فرض خود را حفظ می‌کنند. جدول زیر از سرویس در حال اجرا خوانده می‌شود و پیش‌فرض‌های تعریف‌شده را نشان می‌دهد، نه مقادیر فعلی را؛ مقدار پیش‌فرض خالی هنگام راه‌اندازی محاسبه می‌شود.

## هوک‌ها

`--transparent-hook` فایل اجرایی‌ای را مشخص می‌کند که پیش و پس از راه‌اندازی و برچیدن پروکسی شفاف، با آرگومان‌های `--transparent-type=<redirect|tproxy|tun|system_proxy>`، `--stage=<pre-start|post-start|pre-stop|post-stop>` و `--v2raya-confdir=<directory>` اجرا می‌شود. `--core-hook` پیش و پس از راه‌اندازی و توقف هسته، با `--stage` و `--v2raya-confdir` اجرا می‌شود. اسکریپت‌های مسیریابی `tun` در حالت خاموش بودن **مسیریابی خودکار**، تنظیم جداگانه‌ای دارند: **پیکربندی اسکریپت مسیریابی**.

## پوشه‌ها

| مورد                                         | محل                                                                                                                                                                                                                                                            |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| پیکربندی و `v2raya.db`                       | `--config`؛ پیش‌فرض در Linux و macOS برابر با `/etc/v2raya`، برای سرویس Windows برابر با `%ProgramData%\SYSTEM\v2rayA` و در حالت lite برابر با `~/.config/v2raya` (یا `%AppData%\v2rayA`) است                                                                  |
| پیکربندی تولیدشدهٔ هسته                      | `config.json` در پوشهٔ پیکربندی                                                                                                                                                                                                                                |
| داده‌های قوانین (`geoip.dat`، `geosite.dat`) | `--v2ray-assetsdir`؛ در غیر این صورت پوشه‌های دادهٔ XDG جست‌وجو می‌شوند (`/usr/share/v2raya`، `/usr/local/share/v2raya`، `~/.local/share/v2raya`) و فایل بارگیری‌شده در پوشهٔ دادهٔ کاربر قرار می‌گیرد؛ در Windows، پوشهٔ `data` برنامهٔ نصب یا پوشهٔ پیکربندی |
| هسته                                         | `--v2ray-bin`؛ پیش‌فرض، `v2raya_core` در کنار `v2raya` یا در `PATH` است                                                                                                                                                                                        |
| گزارش‌ها                                     | `--log-file` یا `V2RAYA_LOG_FILE`، وگرنه کنسول؛ واحد سیستمی Linux از `/var/log/v2raya/v2raya.log`، واحد کاربری از `~/.local/state/v2raya/v2raya.log` و برنامهٔ نصب Windows از `%TEMP%\v2raya.log` استفاده می‌کند                                               |
