# Устранение неполадок

Сначала проверьте журнал сервиса: `/var/log/v2raya/v2raya.log` при работе через юнит сервиса в Linux, `journalctl -u v2raya` для вывода самого юнита, в остальных случаях — путь, заданный через `--log-file`. Страница **Журналы** показывает тот же поток; параметр **Уровень журнала** повышает подробность вывода ядра. Сгенерированная конфигурация ядра находится в файле `config.json` в каталоге конфигурации.

## Ядро не запускается

`CORE_START_FAILED` означает, что `v2raya_core` не удалось запустить, оно завершилось сразу после запуска или не открыло порт API за время `--core-startup-timeout`; причина указана в предшествующих строках журнала. Частые причины:

- **Несовпадение версий ядра** — баннер вверху страницы. Версия `v2raya_core` должна совпадать с версией `v2raya`; исполняемый файл `xray` или `v2ray` вместо него не принимается. Установите оба компонента из одного выпуска.
- **`illegal domain rule: geosite:...`** — правило ссылается на категорию, которой нет в `geosite.dat`. Доступные имена перечислены в разделе о маршрутизации.
- **address already in use** — входящий порт занят. Измените его в разделе «Адреса и порты» или остановите другую программу. Порт 53 обрабатывается иначе: если он занят, DNS-модуль не начинает прослушивать этот порт и сообщает об этом в журнале, а в macOS продолжает отвечать существующий DNS-резолвер.
- **`v2raya_core executable not found`** — ядра нет рядом с `v2raya` или в `PATH`; укажите `--v2ray-bin`.

## Нет соединения

- Панель показывает группу и задержку её участников. `TIMEOUT` означает, что с этого компьютера не удалось установить TCP-соединение с сервером; попробуйте другой узел или проверьте подписку.
- Проверьте один входящий порт напрямую: `curl -x socks5h://127.0.0.1:20170 https://example.com`. Если он работает, а прозрачный прокси — нет, прежде чем искать причину в узле, проверьте настройку прозрачного прокси, правила DNS и группу, в которую прозрачный прокси направляет трафик.
- При использовании `redirect` или `tproxy` Docker или межсетевой экран могли заменить правила iptables; остановите и запустите ядро, чтобы установить их заново.
- В Windows и macOS приложение, напрямую запрашивающее DNS-сервер локальной сети, обходит TUN.

## Данные правил

После обнаружения ядра запуск без `geoip.dat` или `geosite.dat` приводит к скачиванию недостающего файла с GitHub; если скачивание не удаётся, запуск завершается. Скопируйте файлы в каталог данных правил вручную (см. раздел о параметрах) или установите пакет, который их содержит.

## После обновления

База данных BoltDB из старого выпуска переносится в новый формат при первом запуске; старый файл остаётся как `bolt.db.bak` (`bolt.db.bak.1` и далее, если это имя занято), а учётные записи нужно зарегистрировать заново. Перед обновлением остановите сервис и скопируйте каталог конфигурации, чтобы перенос можно было повторить из этой копии.

## Сброс пароля

Остановите сервис, выполните `v2raya --reset-password` от имени учётной записи сервиса с теми же флагами `--config` и `--lite` (в Windows каталог сервиса находится в `%ProgramData%\SYSTEM`, а не в каталоге пользователя с повышенными правами), снова запустите сервис и зарегистрируйтесь.
