# Флаги и переменные окружения

У каждого флага есть одноимённая переменная окружения: для `--log-level` это `V2RAYA_LOG_LEVEL`. Юнит сервиса в Linux задаёт `V2RAYA_LOG_FILE` и читает `/etc/default/v2raya`; остальные параметры сохраняют значения по умолчанию. Таблица ниже получена от работающего сервиса и показывает объявленные значения по умолчанию, а не действующие значения; если значение по умолчанию пусто, оно вычисляется при запуске.

## Хуки

`--transparent-hook` задаёт исполняемый файл, который запускается до и после настройки и отключения прозрачного прокси, с аргументами `--transparent-type=<redirect|tproxy|tun|system_proxy>`, `--stage=<pre-start|post-start|pre-stop|post-stop>` и `--v2raya-confdir=<directory>`. `--core-hook` запускается до и после запуска и остановки ядра, с аргументами `--stage` и `--v2raya-confdir`. Скрипты маршрутизации для `tun` при выключенном параметре **Автоматическая маршрутизация** задаются отдельно: **Настроить скрипт маршрутизации**.

## Каталоги

| Что | Где |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| конфигурация и `v2raya.db` | `--config`; по умолчанию `/etc/v2raya` в Linux и macOS, `%ProgramData%\SYSTEM\v2rayA` для сервиса Windows, `~/.config/v2raya` (или `%AppData%\v2rayA`) в режиме lite |
| сгенерированная конфигурация ядра | `config.json` в каталоге конфигурации |
| данные правил (`geoip.dat`, `geosite.dat`) | `--v2ray-assetsdir`; иначе поиск ведётся в каталогах данных XDG (`/usr/share/v2raya`, `/usr/local/share/v2raya`, `~/.local/share/v2raya`), а скачанный файл попадает в пользовательский каталог; в Windows — каталог `data` установщика или каталог конфигурации |
| ядро | `--v2ray-bin`; по умолчанию `v2raya_core` рядом с `v2raya` или в `PATH` |
| журналы | `--log-file` или `V2RAYA_LOG_FILE`, иначе консоль; системный юнит Linux использует `/var/log/v2raya/v2raya.log`, пользовательский юнит — `~/.local/state/v2raya/v2raya.log`, установщик Windows — `%TEMP%\v2raya.log` |
