# 快速开始

v2rayA 在浏览器里使用。服务以 root（Windows 上为管理员）运行并代为启动 `v2raya_core`；浏览器只编辑配置、显示状态。

## 登录

第一个注册的账户就是管理员，没有其他账户。注册不需要任何凭据，因此在共享网络中先限制谁能访问 2017 端口再注册，或者只在本机使用时以 `--address 127.0.0.1:2017` 启动服务。

忘记密码时停止服务，在命令行重置：

```sh
v2raya --reset-password
```

服务带 `--config <目录>` 运行时要加上同样的参数；lite 模式加 `--lite`。

## 导入节点

在**代理**页点**导入**，可粘贴分享链接（`vmess://`、`vless://`、`ss://`、`trojan://`、`hysteria2://`、`tuic://`、`juicity://`、`anytls://`、`wireguard://`、`socks5://`、`http://`、`https://`）、订阅地址、每行一条的多条链接，或者选择二维码图片。ShadowsocksR 链接会被拒绝。

订阅的节点归在一起，可手动更新，也可按计划更新（**设置 → 自动更新订阅**）。旁边的模式选项决定更新是否经过代理。

## 分组

节点通过**代理分组**使用。分组 `proxy` 始终存在，其他分组在代理页添加。从节点菜单或多选后把节点加入分组。组内有多个已连接成员时按实测延迟负载均衡；仪表板的**编辑分组**可固定一个成员，此后该组只经它出站；分组设置里设定探测地址与间隔。

分流规则以分组名作为出口：默认是 `proxy`，其他分组在有已连接成员后按名称使用。

## 启动内核

仪表板的**启动**或页面顶部的状态按钮以当前配置启动 `v2raya_core`。之后在设置页或分组里的每次修改都会自动重启内核生效。

内核运行后，应用通过本机入站使用它：

| 入站 | 地址 | 分流 |
| --- | --- | --- |
| SOCKS5 | `127.0.0.1:20170` | 与透明代理设置相同，未开透明代理时全部走代理 |
| HTTP | `127.0.0.1:20171` | 同上 |
| 带规则的 HTTP | `127.0.0.1:20172` | **规则端口的分流模式**设置 |

端口在**设置 → 地址与端口**修改，0 表示关闭该入站。要让所有应用的流量都经过而不逐个配置，请开启透明代理。

## 分流

**设置 → 流量分流**决定规则端口和透明代理如何分流：国内站点直连其余走代理、只代理 GFWList，或者自己写的 RoutingA 规则。RoutingA 见单独一节。
